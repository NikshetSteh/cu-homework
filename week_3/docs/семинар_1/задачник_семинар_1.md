# Java 1. Неделя 3 — Семинар №1

## Классы и объекты

На семинаре используются три типа задач:

* **Обязательная** — входит в основной маршрут семинара. Такие задачи можно решать самостоятельно или разбирать вместе с преподавателем через live coding.
* **Дополнительная** — более сложная задача по той же теме для самостоятельной работы.
* **Challenge** — одна большая задача повышенной сложности, объединяющая несколько тем недели.

Перед реализацией каждой задачи сначала определи:

1. какие сущности есть в задаче;
2. какие данные относятся к состоянию объекта;
3. какие действия должны быть поведением объекта;
4. что должно быть `private`;
5. какие операции нужно предоставить через `public`;
6. что относится к конкретному объекту, а что — к классу в целом.

# 1. Состояние и поведение объекта

## Задача 1. Абонемент

**Обязательная**

**Ориентировочное время:** 15 минут

Создай класс `Subscription` для абонемента в спортивный зал.

Абонемент хранит:

* имя владельца;
* количество оставшихся посещений.

Все поля должны быть `private`.

Объект создаётся через конструктор:

```java
Subscription subscription = new Subscription("Anna", 5);
```

Абонемент должен позволять:

* узнать количество оставшихся посещений;
* проверить, можно ли ещё посетить зал;
* использовать одно посещение;
* добавить несколько посещений.

### Правила

* начальное количество посещений не может быть отрицательным;
* добавить можно только положительное количество посещений;
* использовать посещение можно только тогда, когда хотя бы одно осталось;
* количество посещений никогда не должно становиться отрицательным.

### Пример 1

```text
Входные данные:
owner = "Anna"
visits = 3

Действия:
visit()
visit()
addVisits(2)

Результат:
Осталось посещений: 3
Можно посетить зал: true
```

### Пример 2

```text
Входные данные:
owner = "Alex"
visits = 1

Действия:
visit()
visit()

Результат:
Осталось посещений: 0
Можно посетить зал: false
```

Неудачная операция не должна изменять состояние объекта.

name = "Keyboard"

### Пример 2

Входные данные:
name = "Mouse"
price = 20
quantity = 5

Действия:
reserve(10)

Всего товара: 5
Зарезервировано: 0

# 2. Взаимодействие объектов и ссылки

## Задача 3. Перевод между счетами

**Обязательная**

**Ориентировочное время:**  15 минут

Создай класс `BankAccount`.

Счёт хранит:

* владельца;
* баланс.

Все поля должны быть `private`.

Добавь метод:

```java
transferTo(BankAccount target, int amount)
```

Он переводит деньги с текущего счёта на другой объект `BankAccount`.

### Правила

Перевод не выполняется, если:

* `amount <= 0`;
* денег на текущем счёте недостаточно;
* `target == null`;
* текущий и целевой счёт — один и тот же объект.

Если перевод возможен:

* баланс текущего счёта уменьшается;
* баланс целевого счёта увеличивается.

### Пример 1

```text
Входные данные:

Anna:
balance = 1000

Bob:
balance = 400

Действие:
anna.transferTo(bob, 300)

Результат:
Anna: 700
Bob: 700
```

### Пример 2

```text
Входные данные:

Anna:
balance = 1000

Действие:
anna.transferTo(anna, 500)

Результат:
Anna: 1000
```

### Для проверки ссылочной модели

Выполни:

```java
BankAccount first = new BankAccount("Anna", 1000);
BankAccount second = first;

second.deposit(200);
```

Перед запуском определи, какой баланс будет доступен через `first`.

## Задача 4. Передача энергии

**Дополнительная**

**Ориентировочное время:**  15 минут

Создай класс `Battery`.

Батарея хранит:

* название;
* текущий заряд;
* максимальную ёмкость.

Все поля должны быть `private`.

Добавь метод:

```java
transferTo(Battery target, int amount)
```

Он должен передать заряд другой батарее.

Но передать можно только столько энергии, сколько одновременно:

* есть в текущей батарее;
* помещается в целевую батарею;
* не превышает запрошенное `amount`.

Метод должен вернуть количество энергии, которое действительно удалось передать.

### Пример 1

```text
Входные данные:

A:
charge = 80
capacity = 100

B:
charge = 20
capacity = 50

Действие:
a.transferTo(b, 40)

Результат:
Передано: 30
A: 50
B: 50
```

### Пример 2

```text
Входные данные:

A:
charge = 10
capacity = 100

B:
charge = 0
capacity = 100

Действие:
a.transferTo(b, 50)

Результат:
Передано: 10
A: 0
B: 10
```

### Правила

Нельзя передавать заряд:

* в `null`;
* самому себе;
* если `amount <= 0`.

# 3. Массивы объектов, возврат объектов и `null`

## Задача 5. Лучший кандидат

**Обязательная**

**Ориентировочное время:**  15 минут

Создай класс `Candidate`.

Кандидат хранит:

* имя;
* балл за тест;
* количество выполненных проектов.

Все поля должны быть `private`.

Напиши статический метод:

```java
findBest(Candidate[] candidates, int minProjects)
```

Метод должен найти лучшего кандидата среди тех, у кого количество проектов не меньше `minProjects`.

Кандидаты сравниваются так:

1. выше балл за тест;
2. если баллы равны — больше проектов;
3. если и это совпадает — раньше находится в массиве.

В массиве могут встречаться элементы `null`.

Если подходящего кандидата нет, метод должен вернуть `null`.

### Пример 1

```text
Входные данные:

candidates =
[
    Candidate("Anna", 85, 2),
    null,
    Candidate("Bob", 92, 1),
    Candidate("Kate", 92, 3)
]

minProjects = 2

Результат:
Kate
```

### Пример 2

```text
Входные данные:

candidates =
[
    Candidate("Anna", 70, 1),
    null
]

minProjects = 3

Результат:
null
```

После получения результата:

```java
Candidate best = findBest(...);
```

измени состояние найденного кандидата через публичный метод.

Проверь, изменился ли соответствующий объект внутри исходного массива.

## Задача 6. Подбор аудитории

**Дополнительная**

**Ориентировочное время:**  15 минут

Создай класс `Room`.

Аудитория хранит:

* номер;
* вместимость;
* стоимость аренды;
* занята ли аудитория.

Напиши метод:

```java
findBestRoom(Room[] rooms, int requiredCapacity)
```

Нужно выбрать свободную аудиторию, которая вмещает нужное количество людей.

Из всех подходящих выбирается:

1. аудитория с минимальной стоимостью;
2. если стоимость совпадает — с меньшей вместимостью;
3. если и вместимость совпадает — раньше расположенная в массиве.

Массив может содержать `null`.

Если подходящей аудитории нет, верни `null`.

### Пример 1

```text
Входные данные:

rooms =
[
    Room("A101", 30, 500, false),
    Room("B202", 50, 700, false),
    Room("C303", 40, 600, true),
    Room("D404", 40, 550, false)
]

requiredCapacity = 35

Результат:
D404
```

### Пример 2

```text
Входные данные:

rooms =
[
    Room("A101", 20, 300, false),
    null
]

requiredCapacity = 50

Результат:
null
```

# 4. `static`: состояние объекта и состояние класса

## Задача 7. Заказы

**Обязательная**

**Ориентировочное время:**  15 минут

Создай класс `Order`.

Каждый заказ хранит:

* уникальный номер;
* стоимость;
* оплачен ли заказ.

Номер заказа должен назначаться автоматически при создании объекта.

Первый заказ получает номер `1`, второй — `2` и так далее.

Кроме того, класс должен хранить:

* количество созданных заказов;
* количество оплаченных заказов;
* общую сумму оплаченных заказов.

Добавь метод:

```java
pay()
```

Он оплачивает заказ.

Один заказ нельзя оплатить дважды.

### Пример 1

```text
Действия:

Order first = new Order(500);
Order second = new Order(800);
Order third = new Order(300);

first.pay();
third.pay();

Результат:
first.id = 1
second.id = 2
third.id = 3

Создано заказов: 3
Оплачено заказов: 2
Оплачено на сумму: 800
```

### Пример 2

```text
Действия:

Order order = new Order(500);

order.pay();
order.pay();

Результат:
Оплачено заказов: 1
Оплачено на сумму: 500
```

Самостоятельно реши, какие поля должны быть обычными, а какие — `static`.

# 5. `toString()`, `==` и `equals()`

## Задача 9. Устройства

**Обязательная**

**Ориентировочное время:**  15 минут

Создай класс `Device`.

Устройство хранит:

* серийный номер;
* модель;
* год выпуска.

Все поля должны быть `private`.

Переопредели `toString()`, чтобы объект удобно выводился в консоль.

Для этой задачи два устройства считаются равными по смыслу, если у них совпадает **серийный номер**.

Сгенерируй `equals()` средствами IntelliJ IDEA.

Создай:

```java
Device first =
    new Device("ABC-123", "Phone X", 2025);

Device second = first;

Device third =
    new Device("ABC-123", "Phone X", 2025);

Device fourth =
    new Device("XYZ-999", "Phone X", 2025);
```

Определи результаты:

```java
first == second
first == third
first.equals(second)
first.equals(third)
first.equals(fourth)
```

до запуска программы.

### Ожидаемые результаты

```text
first == second
→ true

first == third
→ false

first.equals(second)
→ true

first.equals(third)
→ true

first.equals(fourth)
→ false
```

После этого выведи все устройства через `System.out.println()` и проверь работу `toString()`.

## Задача 10. Повторяющиеся книги

**Дополнительная**

**Ориентировочное время:**  15 минут

Создай класс `Book`.

Книга хранит:

* ISBN;
* название;
* автора.

Две книги считаются равными, если у них одинаковый ISBN.

Переопредели:

* `toString()`;
* `equals()`.

Дан массив:

```java
Book[] books = {
    new Book("111", "Java", "Alice"),
    new Book("222", "Algorithms", "Bob"),
    new Book("111", "Java", "Alice"),
    new Book("333", "Databases", "Kate"),
    new Book("222", "Algorithms", "Bob")
};
```

Найди количество **различных книг по смыслу**.

Коллекции использовать нельзя.

### Пример 1

```text
Входные данные:
ISBN:
111
222
111
333
222

Результат:
Различных книг: 3
```

### Пример 2

```text
Входные данные:

books =
[
    Book("111", ...),
    Book("111", ...),
    Book("111", ...)
]

Результат:
Различных книг: 1
```

### Ограничение

Для сравнения книг используй `equals()`, а не сравнивай ISBN непосредственно во внешнем алгоритме.

# Challenge

## Мини-банк

**Challenge**

**Ориентировочное время:** 30 минут

Создай класс `BankAccount`.

Каждый счёт хранит:

* уникальный номер;
* владельца;
* баланс.

Все поля должны быть `private`.

Номер счёта назначается автоматически через `static`.

Класс также хранит общее количество успешных переводов.

Добавь:

```java
transferTo(BankAccount target, int amount)
```

Перевод выполняется только если:

* целевой счёт существует;
* целевой счёт не совпадает с текущим;
* `amount > 0`;
* на счёте достаточно средств.

Дан массив счетов:

```java
BankAccount[] accounts = {
    new BankAccount("Anna", 1000),
    new BankAccount("Bob", 400),
    null,
    new BankAccount("Kate", 1500)
};
```

И массив операций:

```java
int[][] transfers = {
    {0, 1, 300},
    {3, 0, 500},
    {1, 3, 1000},
    {0, 0, 100}
};
```

Каждая строка означает:

```text
{индекс отправителя, индекс получателя, сумма}
```

Обработай все операции.

После этого:

1. выведи все существующие счета через `toString()`;
2. выведи количество успешных переводов;
3. найди счёт с максимальным балансом;
4. верни его из отдельного метода;
5. если массив не содержит ни одного счёта, метод должен вернуть `null`.

### Пример

```text
Начальное состояние:

Anna: 1000
Bob: 400
Kate: 1500
```

Операции:

```text
Anna → Bob: 300
Kate → Anna: 500
Bob → Kate: 1000
Anna → Anna: 100
```

Результат:

```text
Anna: 1200
Bob: 700
Kate: 1000

Успешных переводов: 2
Максимальный баланс: Anna, 1200
```

### Ограничения

Нельзя использовать:

* коллекции;
* наследование;
* исключения для управления логикой программы.

Используй:

* классы и объекты;
* `private` / `public`;
* конструктор и `this`;
* массив объектов;
* ссылки и `null`;
* передачу объектов в методы;
* `static`;
* `toString()`.
