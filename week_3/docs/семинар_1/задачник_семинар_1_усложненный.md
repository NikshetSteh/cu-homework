# Java 1. Неделя 3 — Advanced Track

# Система проката автомобилей

**Уровень:** Advanced
**Ориентировочное время:** 90–120 минут

Эта задача предназначена для студентов, которые уверенно работают с классами, объектами, массивами и методами и хотят реализовать небольшую систему из нескольких взаимодействующих объектов.

Нужно самостоятельно определить:

* какие данные принадлежат конкретному объекту;
* какие данные относятся ко всему классу;
* какие объекты должны хранить ссылки друг на друга;
* где должно изменяться состояние;
* как не допустить частичного изменения данных при неуспешной операции;
* какие методы должны быть `private`, а какие `public`.

---

# Что нужно реализовать

Нужно реализовать небольшую систему проката автомобилей.

В системе существуют:

```text
Customer
Car
Rental
CarRentalSystem
```

Связи между объектами:

```text
Customer
    │
    │ арендует
    ▼
Rental
    │
    │ относится к
    ▼
Car
```

При этом объект `Rental` должен хранить ссылки именно на те объекты `Customer` и `Car`, которые участвуют в аренде.

Система должна хранить массивы:

```java
Customer[]
Car[]
Rental[]
```

Коллекции использовать нельзя.

---

# 1. Customer

Создай класс:

```java
Customer
```

Клиент хранит:

* уникальный `id`;
* имя;
* текущий баланс;
* ссылку на текущую активную аренду.

Например:

```java
Customer anna = new Customer("Anna", 200);
```

Каждый новый клиент автоматически получает уникальный номер:

```text
1
2
3
...
```

Для этого используй `static`.

## Правила

Баланс клиента не может быть отрицательным.

Начальный баланс также не может быть отрицательным.

Клиент может одновременно иметь не более одной активной аренды.

Когда активной аренды нет:

```java
activeRental == null
```

Не нужно предоставлять публичный setter:

```java
setBalance(...)
```

который позволяет установить произвольный баланс.

Изменение состояния должно происходить только через осмысленные операции.

---

# 2. Car

Создай класс:

```java
Car
```

Автомобиль хранит:

* государственный номер;
* модель;
* год выпуска;
* стоимость аренды за один день;
* ссылку на текущую активную аренду.

Например:

```java
Car toyota =
        new Car(
                "AA-101",
                "Toyota Corolla",
                2022,
                40
        );
```

Если автомобиль свободен:

```java
activeRental == null
```

Если автомобиль находится в аренде, поле содержит ссылку на соответствующий объект `Rental`.

---

# Равенство автомобилей

Два автомобиля считаются одинаковыми по смыслу, если совпадает их государственный номер.

Переопредели:

```java
equals()
```

Например:

```java
Car first =
        new Car("AA-101", "Toyota", 2022, 40);

Car second =
        new Car("AA-101", "Something else", 2020, 20);
```

Должно выполняться:

```java
first == second
```

```text
false
```

но:

```java
first.equals(second)
```

```text
true
```

# 3. Rental

Создай класс:

```java
Rental
```

Аренда хранит:

* уникальный номер;
* ссылку на клиента;
* ссылку на автомобиль;
* количество оплаченных дней;
* общую стоимость аренды;
* активна ли аренда.

Номер аренды назначается автоматически:

```text
1
2
3
...
```

через `static`.

Например:

```text
Rental #1
Customer: Anna
Car: AA-101
Days: 3
Total price: 120
Active: true
```

---

# Статистика Rental

На уровне класса `Rental` нужно хранить:

* сколько аренд было создано;
* сколько аренд сейчас активно;
* общую сумму денег, успешно полученную за аренды.

Например:

```text
Rentals created: 3
Active rentals: 2
Total revenue: 420
```

Самостоятельно реши, какие поля являются обычными, а какие должны быть `static`.

# 4. CarRentalSystem

Создай класс:

```java
CarRentalSystem
```

Он представляет одну систему проката.

Система хранит:

```java
Customer[] customers;
Car[] cars;
Rental[] rentals;
```

Размер массивов задаётся при создании системы.

Например:

```java
CarRentalSystem system =
        new CarRentalSystem(
                10,
                10,
                20
        );
```

Это означает:

```text
максимум 10 клиентов
максимум 10 автомобилей
максимум 20 аренд
```

Все массивы должны быть `private`.

---

# Добавление клиента

Система должна позволять добавить клиента.

Например:

```java
system.addCustomer(anna);
```

Операция не выполняется, если:

* передан `null`;
* массив клиентов заполнен;
* этот же объект уже находится в массиве.

Метод должен сообщить, удалось ли выполнить операцию.

Например:

```java
boolean added = system.addCustomer(anna);
```

---

# Добавление автомобиля

Добавь:

```java
system.addCar(car);
```

Автомобиль нельзя добавить, если:

* передан `null`;
* массив автомобилей заполнен;
* в системе уже существует автомобиль, равный ему через `equals()`.

То есть:

```java
Car first =
        new Car("AA-101", "Toyota", 2022, 40);

Car second =
        new Car("AA-101", "Toyota", 2025, 100);

system.addCar(first);
system.addCar(second);
```

Второй автомобиль добавлен быть не должен.

---

# 5. Начало аренды

Система должна предоставлять операцию аренды автомобиля.

Например:

```java
Rental rental =
        system.rent(anna, toyota, 3);
```

Если аренда успешно создана, метод возвращает объект:

```java
Rental
```

Если аренду создать нельзя:

```java
null
```

---

# Когда аренда разрешена

Аренда создаётся только если одновременно выполняются все условия:

* клиент не `null`;
* автомобиль не `null`;
* количество дней больше `0`;
* клиент зарегистрирован в этой системе;
* автомобиль зарегистрирован в этой системе;
* у клиента нет другой активной аренды;
* автомобиль свободен;
* клиенту хватает денег;
* в массиве `rentals` есть свободное место.

Стоимость рассчитывается так:

```text
pricePerDay * days
```

Например:

```text
Toyota:
40 в день

days = 3
```

Стоимость:

```text
120
```

---

# Что происходит при успешной аренде

При успешной операции:

```java
Rental rental =
        system.rent(anna, toyota, 3);
```

должно произойти всё следующее:

```text
Anna.balance -= 120
```

создаётся новый объект:

```text
Rental #...
```

клиент начинает ссылаться на эту аренду:

```text
anna.activeRental
        ↓
      Rental
```

автомобиль начинает ссылаться на ту же аренду:

```text
toyota.activeRental
        ↓
      Rental
```

а объект `Rental` хранит ссылки обратно:

```text
Rental
 ├── customer ──→ Anna
 └── car ───────→ Toyota
```

Получается:

То есть несколько объектов содержат ссылки друг на друга.

---

# Важное правило

Если операция аренды невозможна, состояние программы не должно измениться вообще.

Например:

```text
Anna balance = 100
Car price = 60
Days = 2
```

Нужно:

```text
120
```

Но денег недостаточно.

После попытки аренды:

```text
Anna balance = 100
Car всё ещё свободен
Active rentals не изменилось
Revenue не изменилось
Rental не создан
```

Нельзя сначала списать деньги, а потом обнаружить, что операция невозможна.

---

# 6. Продление аренды

Активную аренду можно продлить:

```java
rental.extend(2);
```

Дополнительная стоимость:

```text
car.pricePerDay * additionalDays
```

Продление выполняется только если:

* аренда активна;
* `additionalDays > 0`;
* клиенту хватает денег.

При успешном продлении:

* деньги списываются с клиента;
* количество дней увеличивается;
* общая стоимость аренды увеличивается;
* общая выручка системы аренды увеличивается.

Например:

```text
До:

days = 3
totalPrice = 120
balance = 100

pricePerDay = 40
```

Вызов:

```java
rental.extend(2);
```

После:

```text
days = 5
totalPrice = 200
balance = 20
```

Если денег недостаточно, ничего не изменяется.

---

# 7. Завершение аренды

Добавь:

```java
rental.close();
```

Закрыть можно только активную аренду.

При успешном закрытии:

```text
Rental.active = false
```

клиент снова становится свободен:

```java
customer.activeRental = null;
```

автомобиль снова становится свободен:

```java
car.activeRental = null;
```

Количество активных аренд уменьшается.

---

# Важная часть про ссылки

После:

```java
rental.close();
```

объект `Rental` не исчезает.

Например, массив всё ещё содержит:

```text
rentals[0]
      │
      ▼
Rental #1
```

И сама аренда всё ещё содержит ссылки:

```text
Rental #1
 ├── customer → Anna
 └── car      → Toyota
```

Но:

```java
anna.activeRental == null
```

и:

```java
toyota.activeRental == null
```

Это разные ссылки.

# 10. Лучший свободный автомобиль

Добавь метод:

```java
findBestAvailableCar(int maxPricePerDay)
```

Нужно найти свободный автомобиль, стоимость аренды которого:

```text
<= maxPricePerDay
```

Из подходящих автомобилей выбирается:

1. автомобиль с минимальной стоимостью за день;
2. при одинаковой стоимости — более новый автомобиль;
3. если совпадает и год — тот, который раньше находится в массиве.

В массиве могут быть `null`.

Если подходящих автомобилей нет:

```java
null
```

# Обязательная декомпозиция

Нельзя писать всю программу внутри `main`.

`main` должен в основном:

* создать систему;
* создать исходные объекты;
* добавить их в систему;
* выполнить проверочный сценарий;
* вывести результат.

Вся предметная логика должна находиться внутри соответствующих классов и методов.

Самостоятельно реши:

* кто создаёт `Rental`;
* кто проверяет возможность аренды;
* кто изменяет баланс;
* кто освобождает автомобиль;
* кто очищает ссылку `activeRental`;
* где должна обновляться статистика;
* какие вспомогательные методы нужны.

Это часть задания.

# Инварианты

После любой публичной операции программа должна оставаться в корректном состоянии.

Например, не должно существовать ситуации:

```text
Car считает себя свободным,
но Customer считает, что арендует этот Car
```

или:

```text
Rental active = true,
но Car.activeRental == null
```

или:

```text
с клиента списались деньги,
но Rental не был создан
```

или:

```text
Active rentals = -1
```

Неуспешная операция не должна частично изменять систему.
