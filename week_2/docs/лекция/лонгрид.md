# Java 1. Неделя 2 — Методы, массивы и строки

# Введение

На первой неделе вся программа почти всегда помещалась внутри `main`:

```java
public class Main {

    public static void main(String[] args) {
        // весь алгоритм здесь
    }
}
```

Для маленьких задач это удобно. Но по мере роста программы появляются две новые проблемы.

Первая:

```text
main становится большим
↓
в нём трудно ориентироваться
↓
отдельные части алгоритма хочется вынести
↓
методы
```

Вторая:

```text
данных становится много
↓
отдельная переменная для каждого значения неудобна
↓
нужен способ хранить последовательность
↓
массивы и строки
```

На этой неделе мы научимся:

- разбивать большую программу на методы;
- передавать данные в методы через параметры;
- возвращать результат через `return`;
- понимать область видимости локальных переменных;
- хранить набор однотипных значений в массиве;
- обходить и обрабатывать массив;
- работать со строкой как с последовательностью символов;
- соединять методы, массивы и строки в одной программе.

Главный переход недели:

```text
Неделя 1

«Я могу записать алгоритм на Java»

        ↓

Неделя 2

«Я могу разделить алгоритм
на понятные части
и обработать набор данных»
```

# Методы

## 1. От большого `main` к методам

Рассмотрим программу, которую уже можно написать после первой недели.

Пусть для числа нужно:

- определить, является ли оно чётным;
- посчитать сумму его цифр;
- вывести оба результата.

```java
public class Main {

    public static void main(String[] args) {
        int number = 12345;

        boolean even = number % 2 == 0;

        int digitSum = 0;
        int current = number;

        while (current > 0) {
            digitSum += current % 10;
            current /= 10;
        }

        System.out.println(even);
        System.out.println(digitSum);
    }
}
```

Пока программа небольшая, такой код читается нормально.

Но представим, что теперь программа должна ещё:

- посчитать количество цифр;
- проверить число на простоту;
- найти количество делителей;
- повторить те же вычисления для другого числа.

`main` быстро начинает расти:

```text
получить данные
↓
проверить данные
↓
посчитать сумму цифр
↓
проверить чётность
↓
посчитать количество цифр
↓
проверить простоту
↓
вывести результат
↓
...
```

Возникает естественная идея:

> Каждой самостоятельной подзадаче можно дать имя и вынести её отдельно.

Например:

```java
public static int digitSum(int number) {
    // алгоритм суммы цифр
}
```

Теперь вместо длинного фрагмента внутри `main` можно будет написать:

```java
int sum = digitSum(number);
```

### Основная идея

**Метод** — именованная часть программы, которая решает отдельную подзадачу.

Методы позволяют:

- разбивать большую задачу на маленькие;
- давать подзадачам понятные имена;
- использовать один алгоритм несколько раз;
- скрывать детали реализации;
- делать `main` короче и понятнее.

Схема:

```text
большая задача
↓
подзадачи
↓
методы
```

## 2. Первый метод

Начнём с самого простого случая — метода, который ничего не получает и ничего не возвращает.

```java
public static void printGreeting() {
    System.out.println("Hello!");
}
```

Чтобы выполнить этот код, метод нужно **вызвать**:

```java
printGreeting();
```

Полная программа:

```java
public class Main {

    public static void main(String[] args) {
        printGreeting();
        printGreeting();
    }

    public static void printGreeting() {
        System.out.println("Hello!");
    }
}
```

Результат:

```text
Hello!
Hello!
```

Когда программа доходит до вызова:

```java
printGreeting();
```

происходит примерно следующее:

```text
main
↓
printGreeting()
↓
выполняется код метода
↓
возврат в main
↓
следующая инструкция
```

Метод можно вызвать столько раз, сколько нужно.

---

## 3. Из чего состоит объявление метода

Рассмотрим строку:

```java
public static void printGreeting()
```

На текущем уровне будем читать её так:

```text
public static
→ пока воспринимаем как часть формы метода

void
→ метод ничего не возвращает

printGreeting
→ имя метода

()
→ место для параметров
```

Смысл `public` и `static` станет понятнее после изучения классов и объектов.

Пока достаточно использовать форму:

```java
public static ...
```

для методов, которые мы объявляем внутри `Main`.

## 4. Параметры метода

Метод становится намного полезнее, если может работать с разными значениями.

Например, вместо метода:

```java
public static void printNumber() {
    System.out.println(10);
}
```

можно написать:

```java
public static void printNumber(int number) {
    System.out.println(number);
}
```

Теперь один и тот же метод можно вызвать с разными значениями:

```java
printNumber(10);
printNumber(25);
printNumber(100);
```

Результат:

```text
10
25
100
```

В объявлении:

```java
public static void printNumber(int number)
```

часть:

```java
int number
```

называется **параметром**.

При вызове:

```java
printNumber(10);
```

значение:

```text
10
```

называется **аргументом**.

Схема:

```text
аргумент
10
↓
параметр
number
↓
код метода
```

### Параметр и аргумент

```text
параметр
→ переменная в объявлении метода

аргумент
→ конкретное значение при вызове
```

---

## 5. Несколько параметров

Метод может принимать несколько значений.

Например:

```java
public static void printSum(int a, int b) {
    System.out.println(a + b);
}
```

Вызов:

```java
printSum(10, 20);
```

В момент вызова:

```text
a = 10
b = 20
```

Результат:

```text
30
```

Важно соблюдать:

- количество аргументов;
- порядок аргументов;
- совместимость типов.

Например:

```java
public static void printRange(int from, int to) {
    System.out.println(from);
    System.out.println(to);
}
```

Вызовы:

```java
printRange(1, 10);
printRange(10, 1);
```

передают разные данные:

```text
первый вызов:
from = 1
to = 10

второй вызов:
from = 10
to = 1
```

Порядок аргументов имеет значение.

---

## 6. Возвращаемое значение

До сих пор методы только выполняли действие.

Например:

```java
public static void printSquare(int number) {
    System.out.println(number * number);
}
```

Такой метод может вывести результат, но внешний код не получает это значение.

Часто удобнее, чтобы метод **вычислил результат и вернул его**.

```java
public static int square(int number) {
    return number * number;
}
```

Теперь можно написать:

```java
int result = square(5);
```

После вызова:

```text
square(5)
↓
number = 5
↓
number * number
↓
25
↓
return 25
↓
result = 25
```

---

## 7. Возвращаемый тип и `return`

Рассмотрим:

```java
public static int sum(int a, int b) {
    return a + b;
}
```

Перед именем метода стоит:

```text
int
```

Это **тип возвращаемого значения**.

Метод обещает вернуть значение типа `int`.

Инструкция:

```java
return a + b;
```

делает две вещи:

```text
вычисляет значение
↓
завершает выполнение метода
↓
передаёт значение вызывающему коду
```

Использование:

```java
int result = sum(10, 20);

System.out.println(result);
```

Результат:

```text
30
```

---

## 8. `void` или результат?

Сравним два метода.

### Выполнить действие

```java
public static void printSquare(int number) {
    System.out.println(number * number);
}
```

Использование:

```java
printSquare(5);
```

Метод сам печатает значение.

### Вычислить значение

```java
public static int square(int number) {
    return number * number;
}
```

Использование:

```java
int result = square(5);
```

Теперь результат можно использовать дальше:

```java
if (result > 20) {
    System.out.println("Big");
}
```

### Главное

Если результат нужен другой части программы, обычно лучше вернуть его:

```text
вход
↓
метод
↓
результат
```

а вывод выполнять там, где он действительно нужен.

---

## 9. Вызов метода — это выражение

Метод с возвращаемым значением можно использовать там, где допустимо значение соответствующего типа.

Например:

```java
int result = sum(10, 20);
```

Но можно и сразу:

```java
System.out.println(sum(10, 20));
```

Или:

```java
int result = sum(10, 20) * 2;
```

Или:

```java
if (square(5) > 20) {
    System.out.println("Big");
}
```

Главная идея:

```text
sum(10, 20)
↓
30
```

Поэтому вызов метода можно воспринимать как значение, которое появится после завершения вычисления.

## 10. Частые ошибки при работе с методами

### Ошибка 1. Метод обещает результат, но ничего не возвращает

```java
public static int square(int number) {
    int result = number * number;
}
```

Метод объявлен как:

```text
int
```

значит он должен вернуть `int`.

Правильно:

```java
public static int square(int number) {
    int result = number * number;
    return result;
}
```

---

### Ошибка 2. Попытка получить значение от `void`

Пусть есть:

```java
public static void printSquare(int number) {
    System.out.println(number * number);
}
```

Так нельзя:

```java
int result = printSquare(5);
```

Причина:

```text
void
→ метод не возвращает значение
```

Если результат нужен:

```java
public static int square(int number) {
    return number * number;
}
```

---

### Ошибка 3. Перепутан порядок аргументов

Если:

```java
public static void printRange(int from, int to) {
    ...
}
```

то:

```java
printRange(1, 10);
```

и:

```java
printRange(10, 1);
```

— разные вызовы.

Полезно читать вызов метода вместе с его параметрами:

```text
printRange(1, 10)

from = 1
to = 10
```

## 11. Декомпозиция алгоритма

Вернёмся к знакомой задаче.

Для числа нужно:

- определить чётность;
- найти сумму цифр;
- посчитать количество цифр.

Вместо одного длинного `main` можно выделить три метода:

```java
public static boolean isEven(int number) {
    return number % 2 == 0;
}
```

```java
public static int digitSum(int number) {
    int sum = 0;

    while (number > 0) {
        sum += number % 10;
        number /= 10;
    }

    return sum;
}
```

```java
public static int countDigits(int number) {
    int count = 0;

    while (number > 0) {
        count++;
        number /= 10;
    }

    return count;
}
```

Теперь `main` становится намного проще:

```java
public static void main(String[] args) {
    int number = 12345;

    System.out.println(isEven(number));
    System.out.println(digitSum(number));
    System.out.println(countDigits(number));
}
```

При проектировании метода полезно сначала ответить на три вопроса:

```text
Что делает метод?
Что получает?
Что возвращает?
```

Например:

```text
digitSum

что делает?
→ считает сумму цифр

что получает?
→ целое число

что возвращает?
→ сумму цифр
```

## 12. Хорошие имена методов

Сравним:

```java
public static int f(int x) {
    ...
}
```

и:

```java
public static int countDigits(int number) {
    ...
}
```

Во втором случае по имени понятно, что делает метод.

Часто методы удобно называть действиями:

```text
calculateTotal
findMaximum
countDigits
printResult
```

Для методов, возвращающих `boolean`, естественны имена-вопросы:

```text
isEven
isPrime
hasAccess
containsDigit
```

Хорошо названный код можно читать почти как описание алгоритма:

```java
if (isEven(number)) {
    System.out.println(digitSum(number));
}
```

## 13. Область видимости переменных

Рассмотрим:

```java
public static int square(int number) {
    int result = number * number;
    return result;
}
```

Переменные:

```text
number
result
```

доступны только внутри метода `square`.

Такой код не скомпилируется:

```java
public static void main(String[] args) {
    System.out.println(result);
}
```

Потому что `result` объявлена внутри другого метода.

---

### Переменные внутри блока

То же правило действует для блоков:

```java
if (true) {
    int x = 10;
    System.out.println(x);
}
```

Внутри блока:

```java
System.out.println(x);
```

работает.

Но после блока:

```java
System.out.println(x);
```

переменная уже недоступна.

Основная модель:

```text
метод
└── блок
    └── локальная переменная
```

Переменная доступна только внутри той области, где она объявлена.

Пока не нужно связывать это со:

- stack;
- heap;
- полями класса;
- полями объекта;
- временем жизни объектов.

Эти темы появятся позже.

## 14. Короткая аналогия с Python

Если раньше вы писали:

```python
def square(x):
    return x * x
```

то похожий Java-метод выглядит так:

```java
public static int square(int x) {
    return x * x;
}
```

Главное дополнительное требование Java:

```text
нужно явно указать
↓
тип параметра
+
тип результата
```

## 15. Перегрузка методов

В Java несколько методов могут иметь одинаковое имя, если отличаются параметрами.

Например:

```java
public static int max(int a, int b) {
    return a > b ? a : b;
}
```

и:

```java
public static double max(double a, double b) {
    return a > b ? a : b;
}
```

Это называется **перегрузкой методов**.

Упрощённо:

```text
одно имя
+
разные параметры
=
перегрузка
```

Методы могут отличаться:

- количеством параметров;
- типами параметров;
- порядком параметров.

Подробные правила выбора перегрузки пока не нужны.

## Передача примитивных значений в метод

При вызове метода значение аргумента **копируется** в параметр метода.

```text
переменная вызывающего кода
        ↓
   копия значения
        ↓
параметр метода
```

Параметр метода — это **отдельная локальная переменная**.

Поэтому:

```text
изменили параметр внутри метода
↓
исходная переменная не изменилась
```

### Главное

Для примитивных типов:

```text
int
long
double
boolean
char
...
```

Java передаёт **значение**, а не саму переменную.

```text
аргумент
→ копирование значения
→ параметр
```

Метод работает со своей копией данных.

# Переход к массивам

До сих пор методы получали отдельные значения:

```text
square(number)
sum(a, b)
isEven(number)
```

Но что делать, если нужно обработать сто оценок студентов?

Можно попытаться создать много переменных:

```java
int score1 = 5;
int score2 = 4;
int score3 = 3;
int score4 = 5;
// ...
```

Но такой подход плохо масштабируется:

```text
10 значений
→ ещё терпимо

100 значений
→ неудобно

1000 значений
→ практически невозможно поддерживать
```

Нужен способ хранить много однотипных значений как один набор.

Так появляется **массив**.


---

# Массивы

## 16. Что такое массив

Массив хранит фиксированное количество элементов одного типа.

Например:

```java
int[] scores = {5, 4, 3, 5};
```

Можно представить:

```text
index:      0   1   2   3
          ┌───┬───┬───┬───┐
scores →  │ 5 │ 4 │ 3 │ 5 │
          └───┴───┴───┴───┘
```

Здесь:

```text
scores
→ имя массива

int
→ тип элементов

5, 4, 3, 5
→ элементы

0, 1, 2, 3
→ индексы
```

Главное правило:

```text
индексация начинается с 0
```

Первый элемент:

```java
scores[0]
```

Последний:

```java
scores[scores.length - 1]
```

---

## 17. Создание массива

Массив можно создать двумя основными способами.

### Значения известны заранее

```java
int[] numbers = {10, 20, 30};
```

Получаем:

```text
[10, 20, 30]
```

### Известен только размер

```java
int[] numbers = new int[5];
```

Java создаст массив из пяти элементов.

Для `int` начальные значения будут равны нулю:

```text
[0, 0, 0, 0, 0]
```

Длина массива:

```java
numbers.length
```

Результат:

```text
5
```

---

## 18. Чтение и изменение элементов

Прочитать элемент:

```java
int first = numbers[0];
```

Изменить элемент:

```java
numbers[0] = 100;
```

Например:

```java
int[] numbers = {10, 20, 30};

numbers[1] = 50;
```

После изменения:

```text
[10, 50, 30]
```

Важное свойство массива:

```text
элементы массива можно изменять
```

К строкам мы позже вернёмся и увидим важное отличие.

---

## 19. Границы массива

Пусть:

```java
int[] numbers = {10, 20, 30};
```

Длина:

```text
3
```

Допустимые индексы:

```text
0
1
2
```

Так можно:

```java
numbers[2]
```

Так нельзя:

```java
numbers[3]
```

Последний индекс всегда:

```text
length - 1
```

Для массива длины `3`:

```text
3 - 1 = 2
```

---

## 20. Обход массива через `for`

Чтобы обработать все элементы массива, удобно использовать цикл.

```java
for (int i = 0; i < numbers.length; i++) {
    System.out.println(numbers[i]);
}
```

Здесь:

```text
i = 0
↓
берём numbers[0]

i = 1
↓
берём numbers[1]

i = 2
↓
берём numbers[2]
```

После этого:


условие:

становится ложным.

## 22. `for-each`

Если индекс не нужен, массив можно обойти короче:

```java
for (int number : numbers) {
```

Читать можно так:

> Для каждого `number` в `numbers`.

```text

↓
number = второй элемент
↓
number = третий элемент
↓
...
```

### Когда удобен `for-each`

Если нужно:

- прочитать каждый элемент;
- посчитать сумму;

- найти максимум;
- проверить условие.

Если нужен:

- индекс;
- доступ к соседним элементам;
- изменение элемента массива.

Сравнение:

```text
нужен индекс
→ for

нужно только текущее значение
→ for-each
```

## 27. Изменение элементов массива

Если нужно изменить сами элементы, удобно использовать индекс.

Например, заменим отрицательные числа на ноль:

```java
for (int i = 0; i < numbers.length; i++) {
    if (numbers[i] < 0) {
        numbers[i] = 0;
    }
}
```

Здесь нужен именно:

```java
numbers[i]
```

потому что мы изменяем элемент массива.

## Передача массива в аргументы метода

Метод:

```java
public static void incrementAll(int[] numbers) {
    for (int i = 0; i < numbers.length; i++) {
        numbers[i] = numbers[i] + 1;
    }
}
```

```java
public static void main(String[] args) {
    int[] numbers = {-10, -3, -20};
    incrementAll(numbers);
    System.out.println(Arrays.toString(numbers));
}
```

Результат:

```text
[-9, -2, -19]
```


### Что происходит

Переменная массива хранит **ссылку на массив**.

При вызове метода Java копирует значение этой ссылки:

```text
numbers в main
      ↓
 ссылка на массив
      ↓
копия ссылки
      ↓
numbers в методе
```

Обе переменные указывают на **один и тот же массив**.

Поэтому изменение:

```java
numbers[i] = numbers[i] + 1;
```

изменяет элементы самого массива:

```text
[-10, -3, -20]
       ↓
[-9, -2, -19]
```

### Главное

Java всегда передаёт аргументы **по значению**.

Для примитивного типа копируется само значение:

```text
int
→ копия числа
```

Для массива копируется значение ссылки:

```text
int[]
→ копия ссылки
→ обе ссылки ведут к одному массиву
```

Поэтому изменение **элементов массива** внутри метода видно и после завершения метода.

## 39. Почему `char` можно сравнивать как число?

Получаем текущий символ строки:

```java
char current = text.charAt(i);
```

Например:

```text
current = '5'
```

В Java `char` хранит символ как **числовое значение UTF-16**.

Для цифр значения идут подряд:

| Символ | Числовое значение |
|---|---:|
| `'0'` | 48 |
| `'1'` | 49 |
| `'2'` | 50 |
| `...` | ... |
| `'9'` | 57 |

Поэтому можно проверить, находится ли символ между `'0'` и `'9'`:

```java
current >= '0' && current <= '9'
```

При сравнении Java фактически сравнивает их числовые значения.

Например:

```text
current = '5'

'5' >= '0'
53  >= 48
→ true

'5' <= '9'
53  <= 57
→ true
```

Значит:

```java
current >= '0' && current <= '9'
```

даст:

```text
true
```

### Если символ не цифра

Например:

```text
current = 'A'
```

У `'A'` другое числовое значение, оно не находится в диапазоне от `'0'` до `'9'`.

Поэтому условие вернёт:

```text
false
```

### Главное

```text
char
↓
символ имеет числовое значение
↓
коды '0' ... '9' идут подряд
↓
проверяем попадание в диапазон
↓
true / false
```

То есть мы **не превращаем `char` в `int` вручную** — Java позволяет сравнивать `char` с помощью `<`, `>`, `<=`, `>=`, используя числовые значения символов.

## Передача ССЫЛКИ строки в метод

Код:

```java
public static void main(String[] args) {
    String text = "java";

    changeString(text);

    System.out.println(text);
}

public static void changeString(String text) {
    text = "Some new text";
}
```

При вызове:

```java
changeString(text);
```

в метод передаётся **копия ссылки** на строку `"java"`.

Параметр `text` внутри метода — отдельная локальная переменная.

Дальше:

```java
text = "Some new text";
```

не изменяет переменную `text` из `main`.

Мы только переназначаем локальную переменную метода на другую строку.

```text
в main:
text → "java"

в методе:
text → "java"

после переназначения:
локальный text → "Some new text"

но text в main → "java"
```

Поэтому после завершения метода:

```java
System.out.println(text);
```

выводит:

```text
java
```
