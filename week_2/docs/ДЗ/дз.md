# Java 1. Неделя 2 — Домашнее задание

## Общие требования

В домашнем задании две обязательные задачи:

1. обработка массива;
2. обработка строки.

Используйте только материал первых двух недель:

- переменные и примитивные типы;
- арифметические и логические выражения;
- `if / else`;
- `for`, `while`;
- методы;
- параметры;
- `return`;
- массивы;
- `String`;
- `charAt()`;
- `length` / `length()`;
- `equals()`.

Не использовать:

- коллекции;
- `Stream API`;
- lambda;
- регулярные выражения;
- собственные классы-модели;
- готовую сортировку;
- сторонние библиотеки.

Ввод через `Scanner` не требуется. Исходные данные задаются непосредственно в `main`.

Для каждой задачи:

- основную логику нужно вынести в методы;
- `main` должен в основном создавать данные, вызывать методы и выводить результаты;
- имена методов и переменных должны отражать их назначение;
- решение необходимо проверить минимум на трёх наборах данных.

# Задача 1. Анализ температуры

Создайте файл:

```text
TemperatureAnalyzer.java
```

Дан массив температур за несколько последовательных дней:

```java
int[] temperatures = {12, 15, 14, 18, 21, 21, 17, 19, 23, 20};
```

Также задан температурный порог:

```java
int threshold = 18;
```

Необходимо проанализировать данные.

## Требуется определить

### 1. Среднюю температуру

Результат должен иметь тип `double`.

Для массива из примера:

```text
18.0
```

---

### 2. Минимальную температуру

Для примера:

```text
12
```

---

### 3. Максимальную температуру

Для примера:

```text
23
```

---

### 4. Первый день с максимальной температурой

Если максимальная температура встречается несколько раз, нужен **первый** такой день.

Внутри программы метод должен возвращать **индекс массива**.

При выводе пользователю номер дня считается начиная с `1`.

Например:

```text
индекс = 8
номер дня = 9
```

---

### 5. Количество дней с температурой строго выше средней

Для примера:

```text
21, 21, 19, 23, 20

→ 5
```

Температура, равная средней, не учитывается.

---

### 6. Количество повышений температуры

Нужно определить, сколько раз температура стала выше, чем в предыдущий день.

Например:

```text
12 → 15   повышение
15 → 14   нет
14 → 18   повышение
```

Для исходного массива результат:

```text
5
```

Первый день сравнивать не с чем, поэтому он не участвует в подсчёте.

---

### 7. Самую длинную серию дней с температурой не ниже порога

Для:

```java
int threshold = 18;
```

нужно найти максимальное количество **последовательных дней**, для которых:

```java
temperature >= threshold
```

В исходном массиве есть серии:

```text
18, 21, 21
```

и:

```text
19, 23, 20
```

Поэтому результат:

```text
3
```

---

## Требуемая декомпозиция

В программе должны быть методы со следующим смыслом:

```java
sum(...)
average(...)
findMin(...)
findMax(...)
findFirstMaxIndex(...)
countAboveAverage(...)
countIncreases(...)
longestAtLeastStreak(...)
```

Допускается немного изменить названия, но каждая самостоятельная подзадача должна оставаться отдельным методом.

## Ограничения

- не изменять исходный массив;
- не сортировать массив;
- не создавать дополнительный массив для решения;
- не писать всю логику внутри `main`.

## Пример результата

```text
Average: 18.0
Minimum: 12
Maximum: 23
First maximum day: 9
Above average: 5
Temperature increases: 5
Longest streak >= 18: 3
```

# Задача 2. Проверка пароля

Создайте файл:

```text
PasswordValidator.java
```

Дана строка:

```java
String password = "Java2026!";
```

Необходимо проверить пароль по нескольким независимым правилам.

## Пароль считается корректным, если

### 1. Его длина не меньше 8 символов

```text
length >= 8
```

---

### 2. В нём есть хотя бы одна цифра

Цифрами считаются:

```text
'0' ... '9'
```

---

### 3. Есть хотя бы одна строчная латинская буква

```text
'a' ... 'z'
```

---

### 4. Есть хотя бы одна заглавная латинская буква

```text
'A' ... 'Z'
```

---

### 5. Нет пробелов

В рамках этой задачи пробелом считается символ:

```java
' '
```

---

### 6. Есть хотя бы один специальный символ

Специальным считается символ, который не является:

- латинской буквой;
- цифрой;
- пробелом.

Например:

```text
!
@
#
$
%
```

---

### 7. Первый символ не является цифрой

Например:

```text
Java2026!
→ подходит
```

```text
2Java2026!
→ не подходит
```

---

# Результат каждой проверки

Программа должна вывести результат каждого правила отдельно.

Для:

```java
String password = "Java2026!";
```

ожидается примерно:

```text
Length: OK
Digit: OK
Lowercase: OK
Uppercase: OK
No spaces: OK
Special character: OK
First character: OK

Password is valid
```

Если хотя бы одно правило нарушено:

```text
Password is invalid
```

# Требуемая декомпозиция

Создайте методы:

```java
hasValidLength(...)
hasDigit(...)
hasLowerCase(...)
hasUpperCase(...)
hasSpace(...)
hasSpecialCharacter(...)
startsWithDigit(...)
isValidPassword(...)
```

Метод:

```java
isValidPassword(...)
```

должен использовать остальные проверки и возвращать итоговый результат.

Можно создавать дополнительные небольшие методы, если они делают код понятнее.

Например:

```java
isDigit(...)
isLowerCase(...)
isUpperCase(...)
```

---

# Ограничения

Не использовать:

- регулярные выражения;
- `Character.isDigit()`;
- `Character.isLetter()`;
- `Stream API`;
- коллекции;
- готовые библиотеки проверки паролей.

Для анализа символов использовать сравнения `char`.

Например:

```java
current >= '0' && current <= '9'
```
