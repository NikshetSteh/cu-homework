## 1. Программа и алгоритм

**Алгоритм** — последовательность действий, которая приводит от исходных данных к нужному результату.

Например, такой.

```text
Взять стоимость товара.
Взять количество товаров.
Умножить стоимость на количество.
Вывести результат.
```

На Java этот алгоритм может выглядеть так.

```java
int price = 500;
int count = 3;

int total = price * count;

System.out.println(total);
```

В простой программе обычно встречаются четыре основные вещи:

* **данные** — значения, с которыми работает программа;
* **вычисления** — действия над данными;
* **условия** — выбор действия;
* **повторения** — выполнение одного действия несколько раз.

Общая схема приведена ниже.

```text
задача
  ↓
алгоритм
  ↓
Java-код
  ↓
результат
```

При решении задачи полезно сначала сформулировать алгоритм словами и только потом переводить его в Java.

## 2. Как выполняется Java-программа

Исходный Java-код хранится в файлах с расширением.

```text
.java
```

Например, так.

```text
Main.java
```

Перед выполнением программа проходит несколько этапов.

```text
Main.java
    ↓
компилятор javac
    ↓
Main.class
    ↓
JVM
    ↓
выполнение программы
```

### Компиляция

Компилятор проверяет исходный код и преобразует его в **байткод**.

Например, такой.

```text
Main.java
    ↓
javac
    ↓
Main.class
```

Если код нарушает правила Java, компиляция завершается ошибкой.

### JVM

**JVM — среда, в которой выполняется скомпилированная Java-программа.**

```text
Main.class
байткод
    ↓
   JVM
    ↓
выполнение программы
    ↓
операционная система / компьютер
```

### Что делает JVM

```text
получает .class-файлы
        ↓
читает Java-байткод
        ↓
проверяет, что байткод корректен
        ↓
выполняет инструкции программы
        ↓
управляет выполнением программы
```

### Зачем нужна JVM

Один и тот же байткод можно выполнять на разных системах, если для них существует JVM.

```text
             Main.class
                 ↓
        ┌────────┼────────┐
        ↓        ↓        ↓
    JVM Windows JVM macOS JVM Linux
        ↓        ↓        ↓
     Windows    macOS    Linux
```

> **Java-код компилируется в байткод, а JVM позволяет выполнить этот байткод на конкретной системе.**

## 3. Структура первой Java-программы

Минимальная программа следующая.

```java
public class Main {

    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

На первой неделе достаточно понимать следующую структуру.

```text
Main
└── main
    └── инструкции программы
```

### `Main`

```java
public class Main {
    ...
}
```

`Main` — имя класса.

Если класс публичный и называется `Main`, файл называется следующим образом.

```text
Main.java
```

### `main`

```java
public static void main(String[] args) {
    ...
}
```

С этого места начинается выполнение программы.

Подробно `public`, `static`, `void`, методы, классы и `String[]` будут разобраны позже.

Пока `main` можно воспринимать как стандартную точку входа.

```java
public static void main(String[] args) {
    // код программы
}
```

### Блоки

Фигурные скобки

```java
{
    ...
}
```

задают блок кода.

### Инструкции

Большинство простых инструкций завершаются точкой с запятой.

```java
;
```

Например, так.

```java
int age = 18;
System.out.println(age);
```

### Аналогии с Python

**Java** использует фигурные скобки.

```java
if (true){
    int age = 18;
    System.out.println(age);
}
```

**Python** использует двоеточие и отступы.

```python
if True:
    age = 18
    print(age)
```

**Java**

```java
int age = 18;
System.out.println(age);
```

**Python**

```python
age = 18
print(age)
```

В Java при объявлении переменной явно указывается тип.

```text
int age
```

В Python так.

```text
age
```

В Java большинство простых инструкций заканчиваются точкой с запятой.

```java
;
```

Например, так.

```java
int age = 18;
```

В Python для разделения инструкций используется перенос строки.


### Вывод

```java
System.out.println("Hello");
```

Выводит значение и переводит курсор на новую строку.

```java
System.out.print("Hello");
```

Выводит значение без автоматического перевода строки.

## 4. Переменные

**Переменная** хранит некоторое значение под именем.

```java
int age = 18;
```

Здесь так.

```text
int → тип
age → имя
18  → значение
```

### Объявление и инициализация

```java
int x = 5;
```

Создаётся новая переменная `x` и получает начальное значение `5`.

### Присваивание

```java
x = 10;
```

Переменная уже существует — меняется только её значение.

Важно различать следующее.

```java
int x = 5;
```

и

```java
x = 10;
```

- Первое создаёт переменную.
- Второе изменяет существующую.

Переменную можно объявить и без присваивания ей значения.

```java
int x;
```

Но объявить переменную без указания типа нельзя!

Компилятор (javac) тебя покарает.

```
java: cannot find symbol
  symbol:   variable age
  location: class Main
```

### Изменение через текущее значение

```java
int score = 10;

score = score + 5;
```

После выполнения.

```text
score = 15
```

Сначала вычисляется правая часть.

```text
score + 5
10 + 5
15
```

Затем новое значение записывается обратно в `score`.

### Сокращённая запись

```java
score += 5;
score -= 5;
score *= 2;
score /= 2;
```

Например,

```java
score += 5;
```

означает примерно следующее.

```java
score = score + 5;
```

### Увеличение и уменьшение на единицу

```java
score++;
score--;
```

На первой неделе их можно читать так.

```text
score++ → увеличить score на 1
score-- → уменьшить score на 1
```

### Важно

Переменные хранят **текущее состояние программы**.

Например, так.

```java
int x = 5;
x += 3;
x *= 2;
```

Состояние меняется.

```text
5 → 8 → 16
```

## 5. Примитивные типы данных

Основные примитивные типы первой недели

| **Тип**   | **Что хранит**      |   **Максимальное значение** | **Пример**                     |
| --------- | ------------------- | --------------------------: | ------------------------------ |
| `int`     | Целые числа         |             `2_147_483_647` | `int age = 18;`                |
| `long`    | Большие целые числа | `9_223_372_036_854_775_807` | `long value = 5_000_000_000L;` |
| `double`  | Дробные числа       |  ≈ `1.7976931348623157E308` | `double price = 199.99;`       |
| `boolean` | `true`/`false`      |                           — | `boolean active = true;`       |
| `char`    | Один символ         |        `'\uFFFF'` (`65535`) | `char grade = 'A';`            |

Также существуют другие типы.

```text
byte
short
float
```

На первой неделе они почти не понадобятся.

### `int`

Для обычных целых чисел

```java
int age = 18;
int count = 5;
int temperature = -10;
```

### `long`

Для больших целых значений

```java
long population = 8_000_000_000L;
```

Суффикс `L` показывает, что литерал имеет тип `long`.

### `double`

Для значений с дробной частью

```java
double price = 199.99;
double temperature = 21.5;
```

### `boolean`

Только два значения

```java
boolean hasAccess = true;
boolean gameOver = false;
```

### `char`

Один символ

```java
char grade = 'A';
```

Для `char` используются одинарные кавычки.

```java
'A'
```

Двойные кавычки используются для строк.

```java
"A"
```


Строка не является примитивным типом! Их мы разберём отдельно на следующей лекции.


## Зачем нужен тип?

### Тип влияет на допустимые значения

Ок
```java
int age = 18;
double price = 199.99;
boolean hasAccess = true;
char grade = 'A';
```

НЕ ок
```java
int age = true;       // ошибка
int age = 18.5;     // ошибка
```

### Тип влияет на доступные операции


С числовыми типами можно выполнять арифметические операции.

```java
int a = 10;
int b = 3;

int sum = a + b;
int product = a * b;
```

С boolean работают логические операции.

```java
boolean hasTicket = true;
boolean isAdult = false;

boolean canEnter = hasTicket && isAdult;
```

То есть тип помогает Java понимать, какие действия имеют смысл для конкретного значения.

### Тип влияет на результат вычислений

Особенно важно это при делении.
```
5 / 2
```

Оба числа имеют тип int, поэтому выполняется целочисленное деление.
```
5 / 2 → 2
```

Дробная часть отбрасывается.

Если хотя бы один операнд имеет тип double,
```
5.0 / 2
```

результат будет дробным.
```
5.0 / 2 → 2.5
```

## 6. Выражения и арифметические операторы

**Выражение** вычисляется и даёт некоторое значение.

Например, так.

```java
price * count
```

Если:

```text
price = 500
count = 3
```

результат выражения будет следующим.

```text
1500
```

Его можно сохранить.

```java
int total = price * count;
```

Основные арифметические операции

| Оператор | Операция           |
| -------- | ------------------ |
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |

### Целочисленное деление

```java
System.out.println(5 / 2);
```

Результат

```text
2
```

Потому что оба значения имеют целочисленный тип.

```java
System.out.println(5.0 / 2);
```

Результат

```text
2.5
```

### Важный пример

```java
double result = 5 / 2;
```

Выражение выше даст следующее.

```text
2.0
```

Сначала выполняется это.

```text
5 / 2 → 2
```

И только потом значение сохраняется как `double`.

---

### Остаток от деления `%`

```java
17 % 5
```

Выражение выше даёт следующий результат.

```text
2
```

Оператор `%` часто используется в алгоритмических задачах.

#### Проверка чётности

```java
number % 2 == 0
```

#### Последняя цифра

```java
number % 10
```

Например, так.

```text
1234 % 10 → 4
```

#### Удалить последнюю цифру

```java
number / 10
```

При целочисленном делении будет так.

```text
1234 / 10 → 123
```

#### Перевод секунд

```java
int totalSeconds = 367;

int minutes = totalSeconds / 60;
int seconds = totalSeconds % 60;
```

Получаем следующее.

```text
6 минут 7 секунд
```

---

### Приоритет операций

Для первых задач достаточно помнить это.

```text
()
↓
* / %
↓
+ -
```

Например,

```java
2 + 3 * 4
```

даёт следующий результат.

```text
14
```


```java
(2 + 3) * 4
```

А строка выше даёт такой результат.

```text
20
```

## 7. Сравнения и логические выражения

Сравнение — это выражение, результат которого имеет следующий тип.

```java
boolean
```

То есть возможны два варианта.

```text
true
```

```text
false
```

Основные операторы

| Оператор | Значение         |
| -------- | ---------------- |
| `==`     | Равно            |
| `!=`     | Не равно         |
| `>`      | Больше           |
| `<`      | Меньше           |
| `>=`     | Больше или равно |
| `<=`     | Меньше или равно |

Например, данное выражение при подстановке даёт следующий результат.

```java
age >= 18
```

```text
age = 20
```

```text
true
```

### `=` и `==`

```java
age = 18;
```

= — присвоить значение.

```java
age == 18
```

== — проверить равенство.

Это разные операции.

---

### Логическое И — `&&`

Оба условия должны быть истинны.

```java
age >= 18 && hasTicket
```

Например, так.

```text
true && true  → true
true && false → false
```

### Логическое ИЛИ — `||`

Достаточно одного истинного условия.

```java
day == 6 || day == 7
```

### Логическое НЕ — `!`

Меняет значение на противоположное.

```text
!true  → false
!false → true
```

Например, так.

```java
!hasAccess
```

---

### Проверка диапазона

Число от `10` до `100` включительно.

```java
number >= 10 && number <= 100
```

Не стоит писать математическую форму.

```text
10 <= number <= 100
```

В Java диапазон разбивается на два сравнения.

## 8. Преобразование примитивных типов

Java автоматически выполняет преобразование, когда значение можно привести к более «широкому» числовому типу без явного cast.
### Автоматическое преобразование

```java
int x = 10;
double y = x;
```

Результат

```text
y = 10.0
```

Java выполняет преобразование сама для типов.

| Исходный тип | Во что можно автоматически преобразовать  |
| ------------ | ----------------------------------------- |
| `byte`       | `short`, `int`, `long`, `float`, `double` |
| `short`      | `int`, `long`, `float`, `double`          |
| `char`       | `int`, `long`, `float`, `double`          |
| `int`        | `long`, `float`, `double`                 |
| `long`       | `float`, `double`                         |
| `float`      | `double`                                  |


В обратную сторону — автоматически нельзя, нужно явное преобразование.

---

### Явное преобразование

```java
double value = 10.7;

int result = (int) value;
```

Получаем следующий результат.

```text
10
```


```java
(int)
```

Конструкция выше называется **приведением типа**.

### Важно

Это выражение даст следующий результат.

```java
(int) 10.9
```

```text
10
```

Дробная часть отбрасывается, а не округляется.

---

### Дробное деление двух `int`

```java
int a = 5;
int b = 2;

double result = (double) a / b;
```

Теперь делаем следующее.

```text
5 → 5.0
5.0 / 2 → 2.5
```

Получим результат.

```text
2.5
```

Если написать выражение ниже, то порядок действий будет следующим.

```java
double result = (double) (a / b);
```

```text
5 / 2 → 2
```

```text
2 → 2.0
```

Поэтому место приведения имеет значение.

## 9. Условные конструкции

Условие позволяет программе выбрать, какой код выполнять.

### `if`

```java
if (age >= 18) {
    System.out.println("Adult");
}
```

Блок выполняется, только если выражение ниже равно `true`.

```java
age >= 18
```

---

### `if-else`

```java
if (age >= 18) {
    System.out.println("Access granted");
} else {
    System.out.println("Access denied");
}
```

Выполняется только одна ветка.

---

### `else if`

Для нескольких вариантов

```java
if (temperature < 0) {
    System.out.println("Cold");
} else if (temperature < 20) {
    System.out.println("Cool");
} else {
    System.out.println("Warm");
}
```

Условия проверяются сверху вниз.

После первого `true` остальные ветки этой цепочки пропускаются.

---

### Порядок условий важен

Например, рассмотрим.

```java
if (score >= 90) {
    System.out.println("Excellent");
} else if (score >= 60) {
    System.out.println("Pass");
}
```

Правильно сначала проверять более строгое условие.

Если поменять проверки местами, значение `95` сразу попадёт в следующую строчку, и до проверки `>= 90` программа не дойдёт.

```java
score >= 60
```

---

### Сначала словами, потом код

Например, так.

```text
Если число больше 0:
    positive.
Иначе если число меньше 0:
    negative.
Иначе:
    zero.
```

Java

```java
if (number > 0) {
    System.out.println("positive");
} else if (number < 0) {
    System.out.println("negative");
} else {
    System.out.println("zero");
}
```

## 10. Цикл `for`

`for` удобен, когда понятно:

* с какого значения начать,
* до какой границы идти,
* как изменять счётчик.

Например, рассмотрим выражение ниже.

```java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

Результат будет таким.

```text
1
2
3
...
10
```

Общая форма такова.

```java
for (начало; условие; изменение) {
    // тело
}
```

В нашем примере выходит так.

```text
int i = 1 → начальное состояние
i <= 10  → условие продолжения
i++      → изменение
```

---

### Порядок выполнения

```text
инициализация
    ↓
проверка условия
    ↓
если true — тело
    ↓
изменение счётчика
    ↺
```

Когда условие становится `false`, цикл заканчивается.

---

### Сумма чисел

```java
int sum = 0;

for (int i = 1; i <= n; i++) {
    sum += i;
}
```

`sum` постепенно накапливает результат.

Например, так.

```text
sum = 0
↓ +1
1
↓ +2
3
↓ +3
6
```

---

### Подсчёт количества

```java
int count = 0;

for (int i = 1; i <= n; i++) {
    if (i % 3 == 0) {
        count++;
    }
}
```

`count` показывает, сколько подходящих значений встретилось.

---

### Условие внутри цикла

```java
for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) {
        System.out.println(i);
    }
}
```

Выводятся только чётные числа.

---

### Следи за границами

```java
i < 10
```

Выражение выше не включает `10`.

```java
i <= 10
```

Выражение выше включает `10`.

Ошибки в таких границах часто приводят к неправильному количеству итераций.

## 11. Цикл `while`

`while` удобно использовать, когда алгоритм естественно читается как:

> повторять, пока выполняется условие.

Например, следующее выражение.

```java
int i = 1;

while (i <= 10) {
    System.out.println(i);
    i++;
}
```

Общая форма такова.

```java
while (condition) {
    // действия
}
```

Перед каждой итерацией Java проверяет условие.

---

### Важно изменять состояние

Ошибка

```java
int i = 1;

while (i <= 10) {
    System.out.println(i);
}
```

`i` остаётся равным `1`.

Поэтому выражение ниже будет выполняться снова и снова.

```text
1 <= 10 → true
```

Получится бесконечный цикл.

---

### Состояние должно двигаться к завершению

Даже если переменная меняется, этого недостаточно.

```java
int i = 1;

while (i <= 10) {
    i--;
}
```

Получаем следующее.

```text
1 → 0 → -1 → -2 → ...
```

Условие остаётся истинным.

---

### Пример с цифрами числа

Количество цифр

```java
int number = 12345;
int count = 0;

while (number > 0) {
    number /= 10;
    count++;
}
```

Состояние

```text
12345 → 1234 → 123 → 12 → 1 → 0
```

Результат

```text
count = 5
```

---

### `for` или `while`

Упрощённо выглядит так.

```text
for
→ для значений от ... до ...
→ повторить N раз
```

```text
while
→ повторять, пока ...
→ количество повторений определяется состоянием
```

## 12. `do-while`, `break`, `continue`

Эти конструкции достаточно знать на базовом уровне.

### `do-while`

```java
do {
    // действия
} while (condition);
```

Главное отличие от `while`:

> тело выполняется хотя бы один раз.

Потому что условие проверяется после тела.

---

### `break`

Полностью прекращает текущий цикл.

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

Результат

```text
1
2
3
4
```

---

### `continue`

Пропускает оставшуюся часть текущей итерации.

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }

    System.out.println(i);
}
```

Результат

```text
1
2
4
5
```

Нужно запомнить следующее.

```text
break    → выйти из цикла
continue → перейти к следующей итерации
```

## 13. Основные виды ошибок

### Ошибка компиляции

Код нарушает правила Java.

Например, в следующих случаях.

```java
int age = "18";
```

```java
int age = 18
```

Программа не может нормально скомпилироваться.

---

### Ошибка выполнения

Программа скомпилировалась, но проблема возникла во время работы.

Например, такая.

```java
int result = 10 / 0;
```

Код синтаксически корректен, но выполнить такое деление нельзя.

---

### Логическая ошибка

Программа компилируется и выполняется, но выдаёт неправильный результат.

Например, выполняет выражение ниже.

```java
int total = price + count;
```

Но требовалось другое.

```java
int total = price * count;
```

Компилятор такую ошибку не обнаружит: обе операции допустимы.

### Главное

```text
код компилируется
≠
код решает задачу правильно
```

---

## 14. Как читать ошибку компилятора

Например, такого вида.

```text
Main.java:5: error: incompatible types
```

Здесь расшифровывается так.

```text
Main.java          → файл
5                  → номер строки
error              → ошибка
incompatible types → описание
```

Более полное сообщение может выглядеть так.

```text
Main.java:5: error: incompatible types: String cannot be converted to int
    int age = "18";
              ^
```

Символ ниже помогает найти место, где компилятор обнаружил проблему.

```text
^
```

---

### Что делать

1. Найти **первую** ошибку.
2. Посмотреть файл и номер строки.
3. Прочитать описание.
4. Проверить указанную строку и несколько строк рядом.
5. Проверить:

    * типы;
    * имена переменных;
    * `;`;
    * кавычки;
    * круглые скобки;
    * фигурные скобки.
6. Исправить проблему.
7. Запустить программу снова.

Одна ошибка в начале программы может вызвать много последующих сообщений, поэтому начинать лучше с первой.

## 15. Как собрать решение задачи

Рассмотрим.

> Для чисел от `1` до `n` найти сумму только чётных чисел.

Не начинаем сразу с Java.

### 1. Что дано?

```text
n
```

### 2. Что нужно получить?

```text
sum
```

### 3. Что нужно повторять?

Перебирать следующее.

```text
1, 2, ..., n
```

### 4. Как понять, подходит ли число?

Проверить следующее.

```java
i % 2 == 0
```

### 5. Что делать с подходящим числом?

```java
sum += i;
```

Получается алгоритм.

```text
Создать сумму 0.

Для каждого числа от 1 до n:
    если число чётное:
        добавить его к сумме.

Вывести сумму.
```

Java

```java
int n = 10;
int sum = 0;

for (int i = 1; i <= n; i++) {
    if (i % 2 == 0) {
        sum += i;
    }
}

System.out.println(sum);
```
