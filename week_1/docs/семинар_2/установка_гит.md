# Установка и настройка Git для курса Java 1

Git будет использоваться:

- из IntelliJ IDEA;
- из встроенного Terminal;
- для работы с GitLab;
- для получения и отправки домашних заданий.

После настройки должны работать команды:

```bash
git --version
git status
git clone ...
git fetch
git push
```

---

# 1. Windows

Самый простой вариант — установить **Git for Windows**.

Можно через `winget`:

```powershell
winget install --id Git.Git -e --source winget
```

Либо скачать Git for Windows с официального сайта Git.

Во время установки для курса обычно можно оставлять настройки по умолчанию.

После установки **перезапустите IntelliJ IDEA и Terminal**.

Проверьте:

```bash
git --version
```

Ожидается что-то вроде:

```text
git version 2.x.x
```

Git for Windows также устанавливает `Git Bash`, но для курса можно пользоваться обычным Terminal внутри IntelliJ IDEA.

---

# 2. macOS

Сначала проверьте:

```bash
git --version
```

Если Git ещё не установлен, самый простой вариант:

```bash
xcode-select --install
```

Эта команда устанавливает Xcode Command Line Tools, в состав которых входит Git.

После установки:

```bash
git --version
```

Если у вас уже установлен Homebrew, можно вместо этого использовать:

```bash
brew install git
```

Оба варианта подходят для курса.

# 6. Первоначальная настройка Git

После установки укажите имя и email:

```bash
git config --global user.name "Ivan Ivanov"
git config --global user.email "ivan@example.com"
```

Лучше указать email, связанный с вашим аккаунтом GitLab.

Проверить:

```bash
git config --global --list
```

---

# 7. Проверяем Git в IntelliJ IDEA

Откройте:

```text
Settings
→ Version Control
→ Git
```

В поле:

```text
Path to Git executable
```

должен быть указан путь к Git.

Например, macOS / Linux:

```text
/usr/bin/git
```

Windows часто:

```text
C:\Program Files\Git\bin\git.exe
```

Нажмите:

```text
Test
```

IDEA должна показать найденную версию Git.

Если всё работает, вручную менять путь не нужно.

---

# 8. Подключаем GitLab

Для курса рекомендуемый вариант аутентификации:

```text
SSH
```

Схема:

```text
ваш компьютер
↓
SSH key
↓
GitLab
```

После настройки не нужно вводить пароль GitLab при каждом `push` или `pull`.

---

# 9. Проверяем наличие SSH-ключа

В Terminal:

```bash
ls ~/.ssh
```

Если там уже есть, например:

```text
id_ed25519
id_ed25519.pub
```

ключ, скорее всего, уже существует.

Важно:

```text
id_ed25519
→ private key
→ никому не отправлять

id_ed25519.pub
→ public key
→ его добавляем в GitLab
```

---

# 10. Создаём SSH-ключ

Если ключа нет:

```bash
ssh-keygen -t ed25519 -C "your-email@example.com"
```

Нажимайте Enter, чтобы использовать стандартный путь:

```text
~/.ssh/id_ed25519
```

Можно установить пароль на SSH-ключ.

---

# 11. Копируем публичный ключ

## macOS

```bash
pbcopy < ~/.ssh/id_ed25519.pub
```

## Windows Git Bash

```bash
cat ~/.ssh/id_ed25519.pub | clip
```

## Linux

```bash
cat ~/.ssh/id_ed25519.pub
```

Скопируйте строку, которая начинается примерно так:

```text
ssh-ed25519 AAAA...
```

Не копируйте приватный файл без `.pub`.

---

# 12. Добавляем ключ в GitLab

В GitLab:

```text
Avatar / Profile
→ Edit profile
→ Access
→ SSH keys
→ Add new key
```

Вставьте публичный ключ и сохраните.

---

# 13. Проверяем подключение к GitLab

Для GitLab.com:

```bash
ssh -T git@gitlab.com
```

Для GitLab курса:

```bash
ssh -T git@git.culab.ru
```

При первом подключении SSH может спросить, доверяете ли вы серверу.

---

# 14. Клонирование репозитория

На странице проекта GitLab:

```text
Code
→ Clone with SSH
```

Получите адрес примерно такого вида:

```text
git@git.culab.ru:group/project.git
```

В IntelliJ IDEA:

```text
Welcome Screen
→ Get from VCS
```

или:

```text
File
→ New
→ Project from Version Control
```

Вставьте SSH URL и нажмите `Clone`.

То же самое через Terminal:

```bash
git clone git@git.culab.ru:group/project.git
```

---

# 15. Проверяем репозиторий

```bash
git status
git remote -v
```

После обычного `clone` должен появиться remote:

```text
origin
```

---

# 16. Настройка репозитория курса

Для workflow курса:

```text
origin
→ личный репозиторий

upstream
→ шаблон курса
```

Добавить шаблон:

```bash
git remote add upstream <URL_ШАБЛОННОГО_РЕПОЗИТОРИЯ>
```

Проверить:

```bash
git remote -v
```

Ожидаемо:

```text
origin    git@git.culab.ru:students/student-repo.git
upstream  git@git.culab.ru:courses/course-template.git
```

---

# 17. Если SSH не работает

Можно использовать HTTPS:

```text
Code
→ Clone with HTTPS
```

Например:

```bash
git clone https://git.culab.ru/group/project.git
```

Если GitLab не принимает обычный пароль аккаунта, используется **Personal Access Token**.

```text
username
→ GitLab login

password
→ Personal Access Token
```

Для курса предпочтительнее один раз настроить SSH.
