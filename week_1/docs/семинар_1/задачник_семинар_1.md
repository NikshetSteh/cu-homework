# Java 1. Неделя 1 — Семинар №1

## Основы языка Java

На семинаре используются три типа задач:

* **Обязательная** — входит в основной маршрут семинара и покрывает ключевые темы занятия. Такие задачи можно решать самостоятельно или разбирать вместе с преподавателем в формате live coding.
* **Дополнительная** — более сложная задача по той же теме для самостоятельной работы.
* **Challenge** — одна большая задача повышенной сложности, объединяющая несколько тем недели.

Для каждой задачи старайся придерживаться одного и того же процесса:

1. прочитай условие;
2. определи, что дано и что нужно получить;
3. сформулируй алгоритм;
4. выбери подходящие конструкции Java;
5. напиши решение;
6. запусти программу;
7. проверь её на нескольких примерах.

Сначала проходи обязательные задачи. Если по какой-то теме обязательная задача уже закончена и есть время, переходи к дополнительной.

# 1. Переменные и вычисления

## Задача 1. Стоимость заказа

**Обязательная**

**Ориентировочное время:** 5 минут

В интернет-магазине известны:

* стоимость одного товара;
* количество товаров;
* стоимость доставки.

Задай эти значения в отдельных переменных.

Вычисли и выведи:

* стоимость всех товаров без доставки;

```text
Входные данные:

count = 4
```


# 3. Условия

## Задача 5. Стоимость доставки

**Обязательная**

**Ориентировочное время:** 10 минут

Стоимость доставки зависит от суммы заказа и расстояния.

Если стоимость заказа не меньше `5000` рублей, обычная доставка бесплатна.

Иначе её стоимость определяется расстоянием:

```text
до 5 км включительно        → 200 рублей
от 6 до 15 км включительно  → 350 рублей
больше 15 км                → 500 рублей
```

Кроме того, заказ может быть срочным.

Если выбрана срочная доставка, к рассчитанной стоимости добавляется ещё `250` рублей.

Исходные данные хранятся в переменных:

```java
int orderAmount = 3200;
int distance = 12;
boolean express = true;
```

Выведи итоговую стоимость доставки.

### Пример 1

```text
Входные данные:
orderAmount = 3200
distance = 12
express = true

Результат:
Стоимость доставки: 600
```

### Пример 2

```text
Входные данные:
orderAmount = 5000
distance = 20
express = false

Результат:
Стоимость доставки: 0
```

## Задача 11. Банкомат

**Обязательная**

**Ориентировочное время:** 15 минут

Банкомат умеет выдавать купюры номиналом:

```text
500 рублей
200 рублей
100 рублей
```

Но количество купюр ограничено:

```text
count500
count200
count100
```

Также дана сумма `amount`, которую хочет снять пользователь.

Нужно определить, можно ли выдать эту сумму имеющимися купюрами.

Если можно, выбери вариант с **минимальным количеством купюр** и выведи, сколько купюр каждого номинала нужно использовать.

Если существует несколько вариантов с одинаковым минимальным количеством купюр, выбери вариант, в котором используется больше купюр по `500` рублей. Если и их количество совпадает — больше купюр по `200` рублей.

Если сумму выдать невозможно, выведи:

```text
Операция невозможна
```

### Пример 1

```text
Входные данные:
amount = 900
count500 = 1
count200 = 2
count100 = 10

Результат:
500: 1
200: 2
100: 0
Количество купюр: 3
```

### Пример 2

```text
Входные данные:
amount = 800
count500 = 1
count200 = 0
count100 = 2

Результат:
Операция невозможна
```

### Ограничение

Не используй массивы и коллекции.

Решение должно учитывать ограниченное количество каждой купюры и искать подходящий вариант, а не считать, что купюр всегда достаточно.

# Challenge

## Счастливые билеты

**Challenge**

**Ориентировочное время:** 25–30 минут

Билет имеет шестизначный номер.

Билет считается **счастливым**, если сумма первых трёх цифр номера равна сумме последних трёх цифр.

Даны два шестизначных номера:

```text
start
end
```

Рассмотри все номера от `start` до `end` включительно.

Найди:

* количество счастливых билетов в диапазоне;
* первый счастливый билет;
* последний счастливый билет.

Если счастливых билетов нет, выведи соответствующее сообщение.

### Пример 1

```text
Входные данные:
start = 100000
end = 100020

Результат:
Количество: 2
Первый: 100001
Последний: 100010
```

### Пример 2

```text
Входные данные:
start = 123320
end = 123330

Результат:
Количество: 2
Первый: 123321
Последний: 123330
```

### Ограничение

Нельзя преобразовывать номер билета в `String`.

Используй только изученные конструкции: переменные, арифметические операции, `/`, `%`, условия и циклы.
