# Java 1. Неделя 1 — Домашнее задание

Домашняя работа предназначена для закрепления материала первой недели.

Задачи не требуют новых конструкций Java. Для решения достаточно использовать:

- переменные;
- арифметические операции;
- `/` и `%`;
- условные конструкции;
- циклы `for` и `while`.

Не используйте:

- массивы;
- строки для анализа цифр числа;
- собственные методы;
- готовые библиотечные методы, которые решают задачу целиком.

---

# Основная часть

## Задача 1. Максимальная цифра и её количество

Дано положительное целое число `number`.

Найдите:

- максимальную цифру числа;
- сколько раз эта цифра встречается.

### Пример

```text
number = 5838582
```

Результат:

```text
maxDigit = 8
count = 3
```

### Ограничение

Нельзя преобразовывать число в строку.

---

## Задача 2. Палиндром

Дано положительное целое число `number`.

Определите, читается ли оно одинаково слева направо и справа налево. Если да - выведите 'Y', если нет - 'N'.

### Пример 1

```text
12321
```

Результат:

```text
Y
```

### Пример 2

```text
12345
```

Результат:

```text
N
```

### Ограничение

Нельзя преобразовывать число в строку.

---

## Задача 3. Делители числа

Дано положительное целое число `n`.

Нужно:

1. вывести все делители числа;
2. посчитать их количество;
3. найти сумму всех делителей.

### Пример

```text
n = 12
```

Делители:

```text
1
2
3
4
6
12
```

Результат:

```text
count = 6
sum = 28
```

Дополнительно определите, является ли число:

```text
prime
```

или:

```text
composite
```

Отдельно проверьте случай:

```text
n = 1
```

---

## Задача 4. Цифровой корень

Дано положительное целое число.

Складывайте его цифры до тех пор, пока не останется одна цифра.

### Пример

```text
number = 9875
```

Первый шаг:

```text
9 + 8 + 7 + 5 = 29
```

Второй шаг:

```text
2 + 9 = 11
```

Третий шаг:

```text
1 + 1 = 2
```

Результат:

```text
2
```

Другой пример:

```text
12345

1 + 2 + 3 + 4 + 5 = 15
1 + 5 = 6

→ 6
```

### Ограничение

Нельзя использовать строки.

# Задача со звёздочкой (необязательная, конечно, но примешь ли ты вызов?)

## Задача 5*. Разложение на простые множители

Дано положительное целое число:

```text
n > 1
```

Выведите его простые множители.

### Пример 1

```text
n = 360
```

Результат:

```text
2 * 2 * 2 * 3 * 3 * 5
```

Потому что:

```text
360 = 2 × 2 × 2 × 3 × 3 × 5
```

### Пример 2

```text
n = 84
```

Результат:

```text
2 * 2 * 3 * 7
```

### Пример 3

Если само число простое:

```text
n = 17
```

Результат:

```text
17
```

### Ограничения

Нельзя:

- использовать массив;
- использовать строку для анализа числа;
- заранее хранить простые числа.

Нужно придумать алгоритм, который последовательно находит делитель и уменьшает исходное число.
