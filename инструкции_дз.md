# Как устроена работа с домашними заданиями


## Первый раз

Репозиторий создаётся через Self Service **один раз на весь курс**.

После этого клонируйте свой репозиторий:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <РЕПОЗИТОРИЙ>
```

Подключите шаблон курса:

```bash
git remote add upstream <URL_ШАБЛОННОГО_РЕПОЗИТОРИЯ>
```

Этот шаг выполняется только один раз.

---

## Как получить новое ДЗ

Например, преподаватель сообщил, что опубликовано ДЗ в ветке `hw-03`.

Получите новые ветки шаблона:

```bash
git fetch upstream
```

Создайте свою ветку на основе задания:

```bash
git switch -c hw-03 upstream/hw-03
```

Отправьте её в свой GitLab:

```bash
git push -u origin hw-03
```

После этого выполняйте задание в ветке `hw-03`.

Обычная работа:

```bash
git add .
git commit -m "Complete hw-03"
git push
```

Для следующего ДЗ действия те же:

```bash
git fetch upstream
git switch -c hw-04 upstream/hw-04
git push -u origin hw-04
```

Новый репозиторий для каждого домашнего задания создавать не нужно.
