# Как устроена работа с домашними заданиями

## Первый раз

Репозиторий создаётся через Self Service **один раз на весь курс**.

После этого клонируйте свой репозиторий:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <РЕПОЗИТОРИЙ>
```

Подключите шаблон курса:

```bash
git remote add upstream <URL_ШАБЛОННОГО_РЕПОЗИТОРИЯ>
```

Этот шаг выполняется только один раз.

---

## Как получить новое ДЗ

Например, преподаватель сообщил, что опубликовано ДЗ `hw-03`.

Все новые задания добавляются в ветку `main` шаблонного репозитория.

Сначала переключитесь на свой `main`:

```bash
git switch main
```

Получите последние изменения из шаблонного репозитория:

```bash
git fetch upstream
```

Команда `git fetch upstream` получает новые commits из шаблонного репозитория и обновляет информацию о:

```text
upstream/main
```

При этом локальный `main` пока не изменяется.

Подтяните изменения из шаблонного `main` в свой локальный `main`:

```bash
git merge upstream/main
```

Теперь локальный `main` содержит актуальные материалы курса.

После этого создайте отдельную ветку для нового ДЗ:

```bash
git switch -c hw-03
```

Отправьте её в свой GitLab:

```bash
git push -u origin hw-03
```

После этого выполняйте задание в ветке `hw-03`.

Обычная работа:

```bash
git add .
git commit -m "Complete hw-03"
git push
```

Для следующего ДЗ действия те же:

```bash
git switch main
git fetch upstream
git merge upstream/main

git switch -c hw-04
git push -u origin hw-04
```

Новый репозиторий для каждого домашнего задания создавать не нужно.

## Именование веток

Чтобы по названию ветки было сразу понятно, для чего она создана, на курсе используем простое соглашение об именовании.

### Домашние задания

```text
hw-01
hw-02
hw-03
...
```

Префикс:

```text
hw-
→ homework
```

Ветки `hw-*` используются **только для домашних заданий курса**.

---

### Собственные эксперименты

Для кода, который не относится непосредственно к сдаваемому ДЗ:

```text
experiment/<название>
```

Например:

```text
experiment/scanner
experiment/arrays
experiment/git-conflicts
```

Такие ветки можно свободно создавать, удалять и переписывать — они не используются для сдачи домашнего задания.
